## Reglas de calidad

- No cambiar solo las cifras de un enunciado para crear otro reactivo.
- Cuatro alternativas distintas con una sola respuesta correcta.
- Un reactivo requiere interpretar datos, contexto, representación u operación diferente.
- No preguntar por el valor posicional de 0.
- Conservar el temario curricular de Matemática (validación de estudios, Mineduc) como referencia, sin atribuir estas preguntas a SIMCE oficial.
- Revisar pedagógicamente con docentes antes de usar fuera de una demo académica.
