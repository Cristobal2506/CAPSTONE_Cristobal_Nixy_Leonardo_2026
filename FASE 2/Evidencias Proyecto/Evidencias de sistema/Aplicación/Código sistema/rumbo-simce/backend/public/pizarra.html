Prueba de escritura de números

Escribe un número con el dedo o con el lápiz y pulsa «Leer». Así funciona la respuesta escrita del diagnóstico y los facsímiles.

Aquí aparecerá lo que leyó el sistema.

Consejo: escribe cada cifra separada de la siguiente, de un tamaño parecido. La coma, pequeña y abajo.
